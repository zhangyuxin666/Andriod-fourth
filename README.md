# 实验五 RecyclerView 翻牌游戏

Android 移动应用开发实验。项目在实验四基础上保留了玩家中心及资料编辑，应用标题为「张雨鑫2024110548」。

- 主界面右上角菜单可打开「关于」对话框。
- 竖屏为 4 列 24 张牌，横屏为 6 列 18 张牌。横竖屏切换时按新规格重新发牌，同一规格下的 Activity 重建恢复当前牌局。
- 每次翻牌扣 1 分。三张同点数加 16 分，三张同花色加 4 分。匹配后锁定三张牌，失败额外扣 2 分并盖回三张牌。
- 重置会重新洗牌并清零当前局得分和进度。每次发牌由同点数三元组组成，初始牌阵存在完整解。

用 Android Studio 打开项目根目录，使用 Android SDK 37 和 JDK 17 或更高版本。Windows 可运行 `gradlew.bat :app:assembleDebug` 生成 APK。若旧版 Windows 工具无法处理中文路径，可将项目放入全英文路径再执行单元测试。

`screenshots/` 保存模拟器截图及核心代码图，`deliverables/` 包含填写好的实验报告。
